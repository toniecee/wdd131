AgriGrow Hub Site Plan

Course: WDD 131: Dynamic Web Fundamentals

Author: Anthony Agbonoga

Site Name

AgriGrow Hub

AG

This name was chosen because the site is a central online resource for crop information, harvest planning, and farmer advisory support. The word "Hub" shows that visitors can find several agriculture-related tools in one place.

Optional domain: agrigrowhub.org

Site Purpose

AgriGrow Hub provides practical crop information for farmers, students, and extension workers. The site includes a crop directory, a harvest yield estimator, and an advisory request form for demonstration purposes. Its purpose is to help users compare crop options, estimate likely harvest output, and understand basic agronomic planning factors.

Scenarios

  • Which crops are suitable for my farm, and how long will they take to mature?
  • How much harvest can I expect from a 2-hectare farm under different management levels?
  • Where can I submit a farm advisory question about pests, soil fertility, or planting schedules?

Typography

The site will use two Google Fonts.

Montserrat will be used for headings, buttons, and logo text.
Open Sans will be used for paragraphs, form labels, navigation text, and crop details.
